## 0. 立项依据(为什么是它)

对准三强归因的四条(`docs/ROADMAP.md` §0):

1. **实体感**:倾斜整机,全身本体感,与最受欢迎的 tilt_maze 同输入;
2. **连续比例 + 群体放大**:一个倾斜动作带动**一整群**(~10 只)小动物哗啦啦滑动——
   单球给不了的"权力感",也是与 tilt_maze 的第一差异轴;
3. **决策随技能成长**:两类动物分归两个家(小鸡→鸡窝、小鸭→池塘),要"先倒一边、再倒
   另一边";群体控制比单球更考验倾斜的轻柔度,倒猛了四散(搞笑场面,不是失败);
4. **收集元循环**:每只归家 = 五声音阶上行一音 + 家门口探头小脸计数;全部归家 = 派对。

**倾倒/归位是幼儿最强图式之一**(见什么倒什么、玩具要回家),语义匹配(动物↔家)比纯
颜色匹配更本能,颜色只做双重编码。

## 1. 复用资产(红线:能复用的不重写)

- **倾斜物理**:`physics.c` 的增益/阻尼/速度封顶/**减除式死区**/低通/轴映射,连同
  tilt_maze 的定案值起步(`TILT_INVERT_X=1` 等,同一台机器同一标定);扩成 N 对象循环。
- **滑行碰撞**:tilt_maze 撞墙滑行代码(边界围栏 + 圆形障碍)。
- **烘焙精灵**:init 时点内测试 + 4×4 超采样烘 ARGB 图(tilt_maze 五角星先例)——小鸡/
  小鸭各一张基础身体图,眼/喙用子对象叠(仿 chain_lab `PRIZE_LOOK` 装扮法)。
- **摇一摇检测**:busy_knobs 的泄漏计数 + 高阈值 + 冷却(`SHAKE_*` 三常量原样抄)。
- **省电**:`core2_sleep` 全托管。**纯 IMU 玩法没有桌面省电坑**——玩的时候机身必然在动,
  `core2_sleep_feed()` 喂加速度即可,无需任何 `core2_sleep_kick`(平台里最省心的一档)。
- **状态机骨架/家长菜单**:仿 tilt_maze `game_state.c`(ATTRACT/PLAY/WIN 三态 + 打盹
  托管);家长菜单等 ROADMAP R2 的 `components/parent_menu` 组件化落地后统一接入,
  组件未就绪则本卡带先不带菜单(与 busy_knobs 等现状一致),**不自己再写一份**。

## 2. 玩法总览

**单屏俯视后院**(静态层一次画完):四周木栅栏;**左边缘中段 = 红顶鸡窝**(门口朝右)、
**右边缘中段 = 蓝色池塘**(缺口朝左);四角各一丛**圆形灌木**(烘进静态层 + 碰撞圆,
把直角变斜坡,**防动物堆死在角落**——这是布局层面的防挫败设计,不是装饰)。

场中散落 **10 只小动物:5 只黄小鸡 + 5 只白小鸭**(半径 ~8px 圆身 + 眼/喙)。倾斜整机,
全体顺"重力"滑动;把小鸡倒进鸡窝、小鸭倒进池塘。**家门是单向门**:进去就不出来
(进度只增不减);进错家 = 被温柔弹开 + 摇头 + 轻"啵"(还没到,不是错)。
10 只全归家 → 派对 → 重新散一批 → 循环。

## 3. 输入 → 机制映射

| 输入 | 来源 | 机制 |
|---|---|---|
| 倾斜向量(x/y) | `imu_mpu6886` + tilt_maze 滤波链 | 全体动物的加速度方向与大小(连续比例) |
| 每只动物的增益抖动 | init 时随机 ±`GAIN_JITTER_PCT`% | 同一倾斜下各自快慢略不同 → 群体自然散开,不结成一坨(有机感的关键) |
| 摇一摇 | busy_knobs 泄漏计数法 | **功能键**(2026-08-10 升级,§13.3):给全体在场动物一个随机方向速度冲量,冲散堵在门口的堆 + 全体原地小跳 + 叽嘎合唱 + 灯带彩虹一闪。冲量方向随机、不指向任何家——解卡是玩家自己接下来的倾斜动作,不是游戏帮忙瞄准 |
| 触摸屏 | — | v1 不用(开放风险 §11⑤) |

## 4. 状态机

```
[ATTRACT] 动物们原地睡(Zzz + 慢呼吸缩放),倾斜超 ATTRACT_TILT_THRESH
   │        → 全体醒来小跳 + 合唱一声 → [PLAY]
[PLAY]    60Hz:读倾斜 → N 对象物理(§5)→ 门判定 → 渲染脏矩形 → 反馈事件
   │        任一动物进对的家 → 捕获动画(§5.3),计数 +1
[PLAY] ──(10 只全归家)──► [PARTY](~3.5s:两家一起弹跳 + 限量彩纸 + SND_WIN
   │                        + HAPTIC_WIN + 灯带彩虹)
[PARTY] ──► [SCATTER](换下一张图纸[§13,依次轮换]→ 整屏重画 → 约束随机布点,§5.4)──► [PLAY]

打盹/深度省电:core2_sleep 全托管,任一状态可进出(同 tilt_maze,唤醒回当前进度,
进度不清零——归家的不放出来)。
```

## 5. 核心机制细则

### 5.1 群体物理(每帧,60Hz)

1. 每只:`acc = tilt_vec × TILT_GAIN × (1 + jitter_i)` → 阻尼 → 封顶(全套 tilt_maze);
2. **两两软分离**:距离 < `2×ANIMAL_R + SEP_PAD` 时沿连线做位置修正(各推一半),
   10 只 = 45 对检查,O(N²) 在此规模可忽略;**不做真刚体碰撞**,软推挤即可(挤挤挨挨
   本身是可爱的);
3. 栅栏/灌木/家的外墙:滑行碰撞(不粘住);
4. 门区判定(§5.3)。

### 5.2 门(单向 + 语义匹配)

- 每家门口一个**门区矩形**(宽 ≈ 动物直径×2,容差给够);
- 动物中心进入门区:**种类匹配** → 捕获;**不匹配** → 沿门法线方向温柔弹出
  (`GATE_BOUNCE_SPEED`)+ 摇头动画(左右各摆一下)+ 轻"啵"音 + `HAPTIC_BUMP_LIGHT`。
  同一只动物的弹出反馈带 `BOUNCE_SND_COOLDOWN_MS` 节流(倾斜顶着门蹭不会机枪音)。
- 🔴 弹出方向按该家的**朝向**(`home_face_t`)算,不写死"鸡窝恒推 +x、池塘恒推 -x"
  ——图纸批(§13)引入门朝向可变的图纸后,两个家可能同向(图纸 B),写死方向会把
  错投动物弹回另一家的墙里。

### 5.3 捕获(所有权交接,防跨任务踩状态)

命中即**从物理仿真中移除**(`active=false`),精灵交给一条 `lv_anim` 演"蹦进门"
(~350ms,位移 + 缩小),完成判定用 game_task 侧帧倒计时(**仿 busy_knobs 小鸟先例:
逻辑坐标存影子变量,不反查 LVGL 对象、不用 anim ready 回调跨任务碰状态**)。
同时:家门口探头小脸 +1(计数显示,鸡窝窗口冒鸡头/池塘水面冒鸭头)、
叽/嘎短鸣 + **五声音阶第 n 音**(n = 已归家总数 1..10,进度天然可听)、
`HAPTIC_COLLECT`、灯带 `LED_FX_COLLECT` 扫圈;归家数 ≥8 时灯带基色加亮一档(冲刺感)。

### 5.4 重散布点(约束随机 + 加载校验)

平台纪律"内容手工编排、别纯随机"(根 CLAUDE.md §11)针对的是**可解性**(迷宫);
本作是开阔场地、无可解性问题,**刻意选择约束随机**换每轮新鲜感,校验兜底:
布点约束 = 两两间距 ≥`SCATTER_MIN_GAP`、离两家门区 ≥`SCATTER_GATE_CLEAR`、避开灌木、
在栅栏内;拒绝采样 `SCATTER_MAX_TRIES` 次不满足则退化为预置网格点(永不失败)。
布完跑一遍校验断言(点数/间距/越界),失败走预置网格 —— 对应 verify 纪律。

🔴 2026-08-10 图纸批(§13)后,重散前先换图纸:网格兜底不能再假设家在场地中段固定
位置(不同图纸家的 `cy` 不同),`flock.c` 的网格兜底改成栅栏内粗网格扫描 + 复用约束
随机同一套合法性判据(而不是写死两行坐标)。`flock_init` 的开局摆位仍用旧的固定两行
(boot 恒为图纸 A,继续安全)。

## 7. 渲染预算合规(根 `CLAUDE.md` §6)

- 静态层:后院地面/栅栏/鸡窝/池塘/四角灌木,进场画一次;
- 动态层:10 只动物 ≈ 18×18 脏矩形 ×2(旧+新)×10 ≈ **6.5k px/帧**,预算(15k)内富余;
  捕获动画/摇头/挤压都是单精灵短脉冲,不叠加超预算;
- 探头小脸计数:归家时改一次,不逐帧;
- 派对彩纸限量 ≤8 片,走 §6.5 庆祝档(15–20fps 可接受);
- 全程不透明色块 + init 烘焙精灵,零运行时 alpha。

## 9. `tuning.h`(默认值 = tilt_maze 定案值起步,★ = 最可能要实机标定)

#define TILT_ALPHA          0.25f

// ── 门 / 布点 ─────────────────────────────────────────

#define GATE_BOUNCE_SPEED   70

## 11. 开放风险(实机验证时决策)

1. **群体手感是本作成败核心**(P1 单独验证):软分离参数不当会"结坨"或"抖动不安";
   增益抖动太小群体像一块砖、太大像没规律。
2. **分拣认知负荷**:3~4 岁对"两类分两家"是否即刻可懂——成功标准同 magic_wand 教训:
   **无人讲解 2 分钟内自发理解**;不行先降 `ANIMAL_KINDS=1` 保底(纯归家也成立)。
3. **最后一只的挫败**:四角灌木 + 软分离理论上防堆死,实机要专门试"最后一只在门口
   反复蹭"的场景。🔴 **2026-08-10 拍板:解法是摇一摇升级成功能键(§13.3),不是
   "最后一只自带轻微向家漂移"**——后者是 ROADMAP §5 明令禁止的"AI 帮玩家瞄准",
   fish_pond 已经死在这条上,本作不重蹈。摇一摇给随机方向冲量,解卡仍是玩家自己
   接下来的倾斜动作。
4. **与 tilt_maze 的差异化靠美术拉开**:俯视后院 vs 迷宫走廊,配色/音色刻意区分。
5. **触摸戳一下动物让它跳**(v1 不做):留作趣味增量批候选,防 v1 范围蔓延。

### 13.1 图纸(blueprint):家会挪、门会转向

单一固定版面(§2 原文的"左鸡窝右池塘")换成**运行时三选一的图纸**(`layout.h` 的

三件套(门垫/框/洞)全部复用,**零美术改动**(所有图纸的门只朝左或朝右,沿边轴恒为
y、进深轴恒为 x)。

### 13.2 运行时接线(`layout.c`/`scene.c`/`flock.c`/`game_state.c`)

1. **家参数化**:`home_spec_t { home_face_t face; float anchor_x, cy; }`;`HOUSE_RECT/
   POND_RECT/HOUSE_GATE/POND_GATE/HOUSE_FACE/POND_FACE/CORNER_BUSH` 从 `extern const`
   改成 `extern` 可写全局量,由 `layout_apply(idx)` 在切图纸时算好写入,
   `flock.c` 原样直接读(**这是本批最容易出错的地方**,以下三条都是它的推论)。
2. 🔴 **门弹出方向按 `home_face_t` 算,不再写死**(旧代码鸡窝恒推 +x、池塘恒推
   -x)——图纸 B 两个家都朝右,写死方向会把错投动物弹回另一家墙里(§5.2)。
3. 🔴 **重散网格兜底改成图纸感知**:旧的"固定两行 y 偏移"假设家在 `cy=120`,图纸
   B/C 挪了 `cy` 后固定两行会踩进新门区;`flock.c` 新增 `scatter_grid_fallback()`
   栅栏内粗网格扫描 + 复用约束随机同一套合法性判据,对任意图纸安全(§5.4)。
   `flock_init` 的开局摆位仍用旧的固定两行——boot 恒为图纸 A,继续成立,不用改。
4. **换图纸 = 整屏重画一次**(合根 `CLAUDE.md` §6.1):`scene_apply_blueprint()` 只在
   PARTY 倒计时结束、`flock_scatter()` 之前调一次,`lv_obj_clean()` 一个专用容器
   (`s_layout`,家×2+灌木×4+探头小脸)后重画,不碰栅栏/草地(图纸无关,只画一次)。
5. **依次轮换,不掷骰子**:开机恒图纸 A,派对后 `(当前+1) % 3`(2026-08-10 用户拍板
   "最简单的就是依次选中")。原方案抄 tilt_maze 的选关洗牌袋,但那套是为 16 关服务的
   ——3 张图纸轮换更短、行为可预期、保证每轮都换。**跨开机不做持久轮转**(2026-08-10
   那版的 NVS 开机计数已删,它是围着"随机数不随机"这个错判打的补丁)。
6. 🔴 **校验器必须能在主机上跑**(2026-08-13 补):几何 + `layout_verify()` 独立成
   `layout.c`(不碰 LVGL),`tools/verify_host.sh` 直接编译真身逐张校验;`scene_init()`
   开机跑一遍 `layout_selftest()` 打日志。理由见 README「'玩多久都只有一张后院'的真因」
   ——校验器自己写错时,游戏静默退化成"永远只有基准图纸",屏幕上与"设计如此"无从分辨。

### 13.3 摇一摇:彩蛋 → 功能键

旧版摇一摇"动物看得见地跳,却什么也没发生"是断因果的彩蛋。改成:`flock_shake_impulse()`
给每只在场动物一个**随机方向**的速度冲量(大小 `SHAKE_IMPULSE_SPEED`,tuning.h,★待实机
标定),把挤在门口的堆冲散——图纸 B 两个门同向,错种类动物在门口悬停堵路是预警过的挫败
场景(§11③)。🔴 冲量方向不指向任何家,解卡仍是玩家自己接下来的倾斜动作,**不是**
§11③ 原提案"仅剩 1 只时向家轻漂移"那种隐形辅助——那条已被 2026-08-10 拍板否决
(ROADMAP §5 红线,fish_pond 的教训)。

### 13.4 美术批(取 `tools/preview.py` 落地值)

| 项 | 旧值 | 新值 | 理由 |
|---|---|---|---|
| `ANIMAL_R` | 8(φ16) | **11(φ22)** | 护眼(根 CLAUDE.md §8);脏矩形 13520px/帧 < 预算 15000,余量仅 10%,**不许再放大** |

| 池塘深水缺口 | `0x2F6E92` | **`0x1F3340`** | 近黑冷色,与鸡窝"黑洞"拉到同一对比度量级 |
| 小鸭身 | `0xF2F2ED` | **`0xE8F0F5`** | 冷白,原色与奶油门框/沙框明度几乎一样,飘到自己家门口会融进背景 |
| 灌木主体/高光 | `0x4E8F4A`/`0x6FB86A` | **`0x7CB86F`**/**`0x8EC980`** | 降视觉权重(碰撞半径不动);原高光 φ24 比主角 φ16 还大,权重是反的 |

🔴 **`GATE_DEPTH` 10→13(未在评审清单里,实施中发现补上)**:`ANIMAL_R` 8→11 后,旧
`GATE_DEPTH=10 < ANIMAL_R=11` 会破坏"动物中心先进门区判定、才可能碰家墙"的不变量
——身体半径比门区判定深度还大,门口会出现一个 <1px 的"先蹭墙、再被门接管"窗口。按

`GATE_DEPTH > ANIMAL_R` 断言防回归。
